# 📱 PWA Installation Guide - SAMB's Laundry Mobile App

## 🎯 **What is a PWA?**
A Progressive Web App (PWA) is a web app that can be installed on your phone just like a native app, with offline capabilities and app-like features.

## 🚀 **How to Install SAMB's Laundry App**

### **Method 1: Install Prompt (Android/Chrome)**
1. **Open the app** on your phone browser
2. **Look for the install prompt** at the bottom
3. **Tap "Install App"** button
4. **Confirm installation** when prompted
5. **App appears** on your home screen!

### **Method 2: Manual Install (iOS Safari)**
1. **Open Safari** on your iPhone/iPad
2. **Go to the app URL** (scan QR code or type URL)
3. **Tap Share button** ⚡ (bottom of Safari)
4. **Scroll down** and tap "Add to Home Screen"
5. **Tap "Add"** to confirm
6. **App icon appears** on your home screen!

### **Method 3: Chrome Menu (Desktop)**
1. **Open app in Chrome browser**
2. **Click install icon** (⊕) in address bar
3. **Click "Install"** button
4. **App installs** on your computer

## 🔍 **Troubleshooting**

### **Install Prompt Not Showing**:
- **Android**: Check Chrome is updated, clear browser cache
- **iOS**: Use Safari browser, not Chrome
- **Desktop**: Check Chrome version, try incognito mode

### **"Add to Home Screen" Missing**:
- **iOS**: Make sure you're in Safari, not Chrome
- **iOS**: Reload the page, try again
- **iOS**: Check if website is fully loaded

### **App Not Working Offline**:
- **First Use**: Connect to internet once after installation
- **Cache Issue**: Clear browser cache and reinstall
- **Update**: Reinstall to get latest version

### **App Icon Not Appearing**:
- **iOS**: Check home screen pages (swipe right)
- **Android**: Check app drawer and home screen
- **Desktop**: Check Chrome apps page
